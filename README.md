# 📌 CiaConsagração

Aplicação web institucional desenvolvida para apresentar a Cia Consagração, com foco em identidade visual, responsividade e navegação por seções.

## 🚀 Tecnologias

* React
* TypeScript
* Vite
* Tailwind CSS
* shadcn/ui

## ✨ Funcionalidades

* Página inicial institucional
* Seções de apresentação, elenco, portfólio e contato
* Layout responsivo
* Componentes reutilizáveis
* Navegação entre páginas
* Página de erro 404

## ⚙️ Como executar

```bash
git clone https://github.com/kayquemab/Projeto_CiaConsagracao
cd CiaConsagracao

# Instalar dependências
npm install

# Executar o projeto
npm run dev
```

## 📌 Observações

* Projeto desenvolvido com React + Vite
* Utiliza Tailwind CSS para estilização
* Possui componentes baseados em shadcn/ui
* Ideal para fins de estudo, prática e portfólio
